# omx/ — OMX Robot Arm Control Team

This folder contains everything related to controlling the OMX robot arm 
for pick-and-place operations.

## Responsibility
Receive detection results from the YOLO team (box location + class), 
move the robot arm to the correct position, pick the box, and place it 
at the destination based on its class (damaged or intact).
